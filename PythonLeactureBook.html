< Python Lists >

What is List?

  • ✓Ordered collection of items that can be of different data types
  • ✓Mutable - elements can be changed after creation
  • ✓Indexed using integers starting from 0

Why Use Lists?

  • ✓Store multiple values in a single variable
  • ✓Dynamic size - can grow/shrink as needed
  • ✓Support various operations like append, remove, sort
  • ✓Allow duplicate values and nested structures

Comparison Table: List vs Tuple

Feature List Tuple
Mutability Mutable Immutable
Syntax [ ] ( )
Performance Slower Faster
Methods Many methods Fewer methods

Applications:

  • ✓Data storage and manipulation in applications
  • ✓Implementing stacks and queues
  • ✓Processing sequences of data (numbers, strings)

Code Example:

l1 = [1, 2, 3, 4, 5]
print(l1)
print(type(l1))
l2 = [10, 2.5, True, 6+9j, "Hello"]
print(len(l2))
for i in l2:
    print(i)
